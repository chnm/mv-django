Import identity

  • Leave Database ID blank to create a new crime record.
  • Use a Database ID from an export to update that exact record.
  • Number is archival metadata; it may be blank or repeated.
  • An unknown Database ID is rejected instead of creating an explicit primary key.

Workflow and file conventions

  • CSV files should use UTF-8 encoding and retain the header row.
  • All columns are optional; include only information supported by the source.
  • Use semicolons between multiple people or weapons in one cell.
  • The preview reports new, updated, and invalid rows before confirmation.
  • Imports over 500 rows omit cell-by-cell HTML diffs to avoid request timeouts.
  • Each confirmed upload creates an Import Batch that can roll back newly created crimes.
  • Rollback does not reverse changes made to records that existed before the import.
